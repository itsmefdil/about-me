# AWS User Group Jogja

**AWS User Group Jogja** is an official community for cloud practitioners, developers, and tech enthusiasts in Yogyakarta interested in Amazon Web Services (AWS) and cloud technology.

As a **Co-Leader Organizer**, Fadilah Riczky co-leads meetup organization, speaker curation, and cloud architectural workshops for local developers.
