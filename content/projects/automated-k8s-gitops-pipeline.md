# Automated K8s GitOps Pipeline

An end-to-end Infrastructure as Code (IaC) and GitOps deployment template designed for cloud-native applications.

## Key Features
- **Automated Provisioning**: Declarative cloud infrastructure using Terraform.
- **GitOps Continuous Delivery**: Application state synchronized via ArgoCD.
- **Security & Quality**: Integrated SonarQube & Trivy vulnerability scanning.
