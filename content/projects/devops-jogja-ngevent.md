# NgEvent - DevOps Jogja Event Platform

An event management application designed specifically to handle registration, ticket generation, and event logistics for **DevOps Jogja** community meetups.

## Key Features
- **Event Registration**: Seamless participant sign-up and ticket verification for workshops and meetups.
- **Modern Web Architecture**: Built using React, Vite, and TypeScript for rapid client-side rendering.
- **Open Source Community Tool**: Developed and maintained collaboratively under the DevOps-Jogja GitHub organization.
