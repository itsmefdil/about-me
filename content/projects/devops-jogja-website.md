# DevOps Jogja Official Website

The official open-source website and community portal for **DevOps Jogja**, serving 500+ infrastructure engineers and tech enthusiasts across Yogyakarta.

## Key Features
- **Event & Schedule Management**: Dynamic listing of upcoming DevOps meetups, workshops, and community gatherings.
- **Blog & Speaker Archives**: Articles and slide archives published by community members.
- **Responsive Dark/Light Mode**: Built with Tailwind CSS and custom theme toggles for smooth dark/light mode switching.
- **Open Source Collaboration**: Maintained open-source by the DevOps Jogja core community.
