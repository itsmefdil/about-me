# Centralized Container Log Observability

A lightweight observability solution built to monitor Docker container logs and health metrics in resource-constrained environments.

## Key Features
- **Real-Time Log Streaming**: Instant container log viewer powered by Dozzle.
- **Metrics Export**: Custom Python exporter providing Docker container metrics to Prometheus.
- **Grafana Dashboard**: Pre-configured dashboards for CPU, memory, and container restart alerts.
