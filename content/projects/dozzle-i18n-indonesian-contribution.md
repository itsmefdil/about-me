# Dozzle - Real-time Docker Log Viewer (Open Source Contribution)

**Dozzle** is a lightweight, web-based log monitoring application designed for Docker containers. It streams container logs in real time with minimal memory footprint and zero configuration.

![Dozzle OpenGraph Banner](https://opengraph.githubassets.com/1/amir20/dozzle)

## My Contribution
- **Indonesian Internationalization (i18n)**: Author of **[Pull Request #3884](https://github.com/amir20/dozzle/pull/3884)** (`feat(i18n): add Indonesian translation`), providing complete localization for the Indonesian user base.
- **Localization Files**: Created `id.yml` containing accurate translations for container controls, log search filters, status indicators, and setting menus.

## Key Features of Dozzle
- **Real-time Log Streaming**: WebSocket-based live log viewer with instant auto-scroll and pause features.
- **Low Footprint**: Ultra-lightweight Go backend requiring minimal CPU/RAM resources.
- **Multi-language Support**: Fully localized in multiple languages including Bahasa Indonesia.
