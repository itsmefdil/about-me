# Manabu - Japanese Learning Helper 🇯🇵

**Manabu** is a feature-rich web application built to streamline Japanese language learning, enabling users to practice and monitor their daily learning progress.

![Manabu OpenGraph Banner](https://opengraph.githubassets.com/d5e8697a5b3a4a159930f3f6c8adcb43310899e4b7b257cf02a3a5f4c54095a9/itsmefdil/manabu-nihongo)

## Key Features
- **Vocabulary Practice**: Interactive flashcards and drills for mastering essential Japanese words.
- **Kanji Tracker**: Stroke order guides, readings (On'yomi/Kun'yomi), and retention tracking for Kanji characters.
- **Grammar Modules**: Structured grammar lessons categorized by JLPT proficiency levels.
- **Modern Full-Stack Stack**: React & Vite frontend connected to a fast Bun + Express backend backed by Drizzle ORM.

## Tech Architecture
- **Frontend**: React (Vite), TypeScript, CSS Modules
- **Backend**: Bun runtime, Express.js (TypeScript)
- **Database & ORM**: SQLite with Drizzle ORM
- **Deployment**: Vercel (Frontend & Serverless Integration)
