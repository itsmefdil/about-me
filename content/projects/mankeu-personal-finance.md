# Mankeu - Personal Finance Management

**Mankeu** is a modern, feature-rich personal finance management application designed to help you track your income, expenses, budgets, and financial goals with ease. Built with a focus on user experience and visual aesthetics, it offers a premium, intuitive interface for managing personal finances.

## Key Features

- **📊 Interactive Dashboard**: Real-time overview of financial health with cash flow trends, expense breakdowns, and budget status.
- **💰 Transaction Tracking**: Easily record and categorize income and expenses with payment method details.
- **📉 Analytics**: Visualize spending habits with detailed charts and graphs using Recharts.
- **🎯 Budget & Goals**: Set monthly budgets and financial goals to stay on track.
- **🏷️ Category & Debt Management**: Track loans, debts, accounts, and custom expense categories.
- **🔐 Secure Authentication**: Google Identity Services (GIS) login and secure session management.
- **📱 Mobile & Dark Mode**: Fully responsive design with dark mode support.

## Tech Stack

### Frontend
- **Framework**: React (Vite)
- **Styling**: TailwindCSS & Vanilla CSS
- **Icons**: Lucide React
- **Charts**: Recharts
- **State Management**: Zustand (Auth/Theme), TanStack Query (Data Sync)

### Backend
- **Runtime**: Bun (v1.x)
- **Framework**: Express (TypeScript)
- **Database & ORM**: MySQL with Drizzle ORM
- **Validation**: Zod
