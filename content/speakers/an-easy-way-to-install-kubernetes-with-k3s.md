# An Easy Way to Install Kubernetes with k3s for Beginners

In this session at **OpenStack & OpenInfra Indonesia Meetup #17**, Fadilah Riczky demonstrated how beginners and DevOps engineers can get started with lightweight Kubernetes using **k3s**.

## Event Overview
- **Event**: OpenStack & OpenInfra Indonesia Meetup #17
- **Date**: Sunday, December 17, 2023 (13:00 - 17:00 WIB)
- **Venue**: Kantor DomaiNesia (Deneva Hub), Jl. Rogoyudan 1 No.2, Sinduadi, Mlati, Sleman, Yogyakarta
- **Speaker**: Fadilah Riczky (DevOps Engineer at Atmatech)

## Key Topics Covered
- **Introduction to k3s**: Lightweight Kubernetes distribution designed for IoT, Edge, and Homelabs.
- **Quick Installation**: Single-binary setup, resource optimization, and node joining.
- **Basic Cluster Operation**: Deploying workloads, managing pods, and configuring ingress controllers.
