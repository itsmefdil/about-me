# Build Your Own Web Server with Linux and Cloudflare Tunnel

In this session at **Community Gathering IT Infrastructure (Paguyuban Linux Solo & FOSTI UMS)**, Fadilah Riczky presented how to host, configure, and secure Linux web servers for homelabs and remote application hosting using **Cloudflare Tunnel**.

## Event Overview
- **Event**: Community Gathering IT Infrastructure
- **Organizers**: Paguyuban Linux Solo & FOSTI UMS (Forum Open Source Teknik Informatika)
- **Date**: Saturday, November 9, 2024 (08:00 WIB - Finish)
- **Venue**: Kampus 2, Gd. J, Lt 4 Ruang J406, Universitas Muhammadiyah Surakarta (UMS), Sukoharjo, Jawa Tengah
- **Speaker**: Fadilah Riczky (DevOps Engineer at Atmatech)

## Key Topics Covered
- **Linux Web Server Setup**: Configuring NGINX/Caddy web servers for hosting applications.
- **Cloudflare Tunnel (`cloudflared`)**: Exposing local services securely to the internet without open inbound ports or public IP addresses.
- **Zero-Trust Security & SSL**: Encrypted SSL/TLS termination, access policies, and DDoS protection via Cloudflare Edge network.
