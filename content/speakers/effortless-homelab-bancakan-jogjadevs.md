# Effortless Homelab

In this talkshow session at **BANCAKAN JogjaDevs 2025**, Fadilah Riczky shared insights and practical tips on building and operating an **Effortless Homelab** for self-hosting services, testing infrastructure automation, and experimenting with cloud-native tech without high cloud bills.

## Event Overview
- **Event**: BANCAKAN JogjaDevs (Gathering All Devs Communities in Yogyakarta)
- **Organizers**: JogjaDevs (DevOps Jogja, JogjaJS, PyLadies YK, DevOps Focus Group, ISQA)
- **Date**: Saturday, December 20, 2025 (08:00 - 16:00 WIB)
- **Venue**: Gedung Herman Yohanes, Sekolah Vokasi Universitas Gadjah Mada (SV UGM), Yogyakarta
- **Speaker**: Fadilah Riczky (DevOps Engineer at Atmatech / DevOps Jogja)

## Key Topics Covered
- **Why Build a Homelab?**: Safe environment for experimenting with Kubernetes, Docker, and IaC.
- **Hardware & Resource Optimization**: Reusing mini PCs, single-board computers, and consumer hardware efficiently.
- **Self-Hosting Best Practices**: Secure remote access with Cloudflare Tunnels, automated backups, and container orchestration.
