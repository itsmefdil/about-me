# What Monitoring Tools Do You Really Need?

In this talk at **Meetup DevOps Jogja #6**, Fadilah Riczky analyzed the modern observability stack and provided a decision framework for selecting the right monitoring tools based on infrastructure scale and operational budget.

- **Speaker**: Fadilah Riczky (Organizer DevOps Jogja)

## Key Topics Covered
- **Observability Landscape**: Comparing metrics (Prometheus), logging (Loki, Dozzle), and uptime monitoring (Uptime Kuma).
- **Avoiding Over-Engineering**: Right-sizing monitoring infrastructure for small-to-medium teams versus enterprise setups.
- **Alert Fatigue Prevention**: Designing actionable Grafana dashboards and proactive notification channels.
